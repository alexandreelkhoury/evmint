# Security Disclosure Policy

If you discover a security vulnerability, please report it privately to
security@evmint.io rather than disclosing it publicly, and give us a
reasonable window to fix it before you do.

# Scope

This security policy applies to:
- Web application (evmint.io)
- Smart contract interactions
- User authentication and wallet connections
- Data handling and privacy

# Out of Scope

- Third-party services (Privy, WalletConnect, RPC providers)
- Blockchain protocols themselves
- User wallet security

# Reporting Guidelines

When reporting a vulnerability, please include:
1. Description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Suggested fix (if applicable)

# Response Timeline

- Acknowledgment: Within 48 hours
- Initial assessment: Within 7 days
- Fix deployment: Based on severity

# Recognition

We appreciate security researchers who help keep our platform safe. If you
would like credit for a disclosure, tell us how you'd like to be named and
we will credit you when the fix ships.

# Additional Information

- Bug Bounty Program: Not currently available
- Encryption: PGP key not yet available
- Policy: https://evmint.io/terms

Thank you for helping keep EVMint and our users safe!
